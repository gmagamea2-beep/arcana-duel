# 아르카나 듀얼 (가제) — 기획서 v0.1

> **한 줄 요약**: 공용 시장에서 카드를 사서 덱을 키우며, 하스스톤처럼 유닛으로 싸워 상대 영웅을 쓰러뜨리는 1:1 덱빌딩 결투 게임.

- 장르: 1:1 덱빌딩 결투 (메인 모드) + 다인원 파티 모드 (보조 모드)
- 플랫폼: Windows `.exe` + Android `.apk`
- 한 판: 10~20분
- 복잡도: 하스스톤 정도
- 개발: 혼자 하는 취미, 알파 버전 최우선, 예산 최대 10,000원, 수익 모델 없음

## 2. 게임 준비

1. 각자 **영웅 1명**을 고름 (4명 중 하나, 상대와 같아도 됨).
2. 각자 **스타터 덱 10장**을 섞음 (두 사람 모두 같은 구성).
3. 시작 상태: **체력 25 / 마나 0 / 골드 0**.
4. 선공은 무작위로 정함.
5. 시작 손패: **선공 4장, 후공 5장**. 후공은 **골드 +1**도 받음 (선공 보정).
6. **멀리건**: 손패에서 원하는 카드를 골라 1회 교체.
7. **시장**: 시장 덱에서 카드 5장을 공개함 (아래 5장 참고).

## 3. 자원

| 자원 | 얻는 법 | 쓰는 곳 | 다음 턴 이월 |
|---|---|---|---|
| **마나** 🔷 | 턴 시작 시 최대 마나 +1 (최대 10) 후 전부 회복 | 카드 사용, 영웅 능력 | ✗ (남으면 사라짐) |
| **골드** 🪙 | 손패 1장을 버릴 때마다 +1, 카드 효과 | 카드 구매, 시장 갱신, 정리 | ✓ (최대 10 보유) |

- 버린 카드는 내 **버린 더미**로 감 (덱이 떨어지면 다시 섞여 돌아옴).
- 스타터 카드 **금화**는 사용하면 골드 +2를 줌 (버리면 +1). 그래서 금화는 버리지 말고 쓰는 게 이득.

## 4. 턴 진행

### ① 시작 단계
1. 최대 마나 +1 (최대 10) → 마나 전부 회복
2. 붕괴 확인 (8-2 참고)
3. '턴 시작 시' 효과 발동 (필드, 유닛)
4. **손패가 5장이 될 때까지 드로우** (이미 5장 이상이면 1장만)
   - 선공의 첫 턴에는 드로우하지 않음
   - 손패 최대 10장. 넘치는 카드는 그대로 버린 더미로
   - 덱이 비면 버린 더미를 섞어서 새 덱으로 만듦

### ② 행동 단계 (아래 행동을 원하는 순서로, 원하는 만큼)
| 행동 | 비용 | 제한 |
|---|---|---|
| 카드 사용 | 카드의 마나 비용 | — |
| 카드 버리기 | 무료 → **골드 +1** | — |
| 카드 구매 | 희귀도별 골드 가격 | 산 카드는 **내 버린 더미로** |
| 시장 갱신 | 1골드 | 턴당 1회. 시장 5장을 모두 교체 |
| 정리 | 2골드 | 턴당 1회. 손패 1장을 게임에서 영구 제거 (약한 스타터 카드 덜어내기) |
| 영웅 능력 | 2마나 | 턴당 1회 |
| 유닛 공격 | — | 유닛 하나당 1회 |

### ③ 종료 단계
- '턴 종료 시' 효과 발동
- 남은 손패는 유지됨 (다음 턴에 5장까지 채움)
- 남은 마나는 사라지고, 골드는 이월 (최대 10)

## 5. 시장

- 시장에는 **항상 5장이 공개**되어 있음. 두 플레이어가 함께 씀.
- 카드를 사면 빈칸은 즉시 **희귀도 가중치 무작위**로 다시 채워짐.
- 희귀도별 등장 확률과 가격:

| 희귀도 | 카드 틀 색 | 등장 확률 | 구매 가격 |
|---|---|---|---|
| 일반 | 회색 | 40% | 2골드 |
| 레어 | 파랑 | 27% | 3골드 |
| 에픽 | 보라 | 16% | 4골드 |
| 레전더리 | 금색 | 10% | 5골드 |
| 미스틱 | 청록 | 5% | 7골드 |
| 얼티밋 | 빨강 (무지개 테두리) | 2% | 9골드 |

- **진영 할인**: 내 영웅과 같은 진영의 카드는 **1골드 할인**.
- **레전더리 이상은 한 게임에 같은 카드가 한 번만** 시장에 나옴 (누가 사면 다시 나오지 않음).
- 스타터 카드와 토큰은 시장에 나오지 않음.

## 7. 카드 종류별 규칙

| 종류 | 규칙 |
|---|---|
| **유닛** | 유닛 칸에 놓임. 낸 턴에는 공격 불가 (돌진은 예외). 죽으면 주인의 버린 더미로 (덱빌딩이라 다시 돌아옴) |
| **주문** | 사용하면 효과가 나오고 버린 더미로 |
| **함정** | 마나를 내고 뒷면으로 놓음. **상대 턴**에 조건이 맞으면 자동 발동 → 공개 → 버린 더미로. 이름이 같은 함정은 동시에 2장 놓을 수 없음 |
| **필드** | 공용 필드 칸에 놓임. "필드 주인" = 그 필드를 낸 사람. 상대가 새 필드를 내면 교체됨 |
| **영웅** | ① 게임 시작 때 고르는 **리더** (체력 25 + 영웅 능력) ② 시장에서 파는 **영웅 카드**: 사용하면 내 영웅이 그 카드로 바뀜 (체력 유지, 방어도와 새 영웅 능력 획득) |

- **연쇄 없음**: 함정에 함정으로 대응할 수 없음. 발동 즉시 처리 (단순함 우선).
- **방어도** 🛡: 영웅이 받는 피해를 체력보다 먼저 깎음. 상한 없음.
- 효과 문구 표기 규칙: "대상 하나" = 유닛 또는 영웅, 적·아군 무관. "적 하나" = 적 유닛 또는 적 영웅. "적 유닛 하나" = 영웅 제외.

## 8. 전투와 승패

### 8-1. 전투
- 공격자가 대상을 고름: 적 유닛 또는 적 영웅.
- **도발** 유닛이 있으면 반드시 도발부터 공격해야 함.
- 유닛끼리 싸우면 **동시에** 서로의 공격력만큼 피해.
- 피해는 계속 남음 (회복 효과로만 회복).
- 체력이 0 이하가 되면 죽음.

### 8-2. 승패와 붕괴
- 상대 영웅 체력이 0이 되면 승리. 둘이 동시에 0이 되면 **무승부**.
- **붕괴** (게임이 늘어지는 것 방지): **내 13번째 턴부터** 턴 시작 시 내 영웅이 `(내 턴 수 − 12)`만큼 피해를 받음 (1, 2, 3, …). 방어도로는 막을 수 없음.
- 턴 제한 시간: AI전은 없음 (옵션으로 90초). 온라인 대전을 추가하면 75초.

## 9. 키워드 (알파 9개)

| 키워드 | 효과 |
|---|---|
| **도발** | 적은 이 유닛부터 공격해야 함 |
| **돌진** | 낸 턴에 바로 공격 가능 |
| **보호막** | 처음 받는 피해 1회를 무효로 함 |
| **독** | 이 유닛에게 피해를 받은 유닛은 즉시 죽음 |
| **흡혈** | 이 유닛이 준 피해만큼 내 영웅의 체력을 회복 |
| **등장** | 손패에서 낼 때 효과 발동 (토큰 소환 시에는 발동 안 함) |
| **유언** | 죽을 때 효과 발동 |
| **동맹** | 이번 턴에 **같은 진영 카드를 먼저 사용했다면** 추가 효과 |
| **구매 시** | 시장에서 살 때 효과 발동 (알파에서는 함정 조건으로만 사용) |

### 11-4. 밸런스 기준 (카드 추가할 때 쓰는 공식)
- 기본 유닛: **비용 N → 공격력 + 체력 ≈ 2N + 1** (예: 3마나 3/4)
- 키워드 가치 (스탯 환산): 도발 0.5 · 돌진 1 · 보호막 1 · 흡혈 1 · 독 1.5 · 카드 1장 뽑기 1.5 · 피해 1당 0.75
- 희귀도가 높을수록 스탯을 +1~2 허용하거나 독특한 효과를 넣음
- 목표 수치 (AI끼리 1,000판 시뮬레이션으로 확인):
  - 선공 승률 45~55%
  - 영웅별 승률 45~55%
  - 평균 게임 길이: 내 턴 기준 9~12턴

## 13. 기술 계획

### 13-1. 엔진: Godot 4 (최신 안정판)
- 무료 (MIT 라이선스). **한 프로젝트로 Windows `.exe`와 Android `.apk`를 모두** 내보낼 수 있음.
- 언어는 GDScript. 렌더러는 **Compatibility** (저사양 안드로이드 호환).
- 화면 설정: stretch mode `canvas_items`, aspect `expand`, 가로 고정.

### 13-2. 폴더 구조
```
arcana-duel/
├─ project.godot
├─ data/            # 카드·영웅 데이터 (JSON) — 코드를 몰라도 수정 가능
│  ├─ cards.json
│  └─ heroes.json
├─ core/            # 규칙 엔진 (화면과 분리 → 시뮬레이션·AI·온라인에 재사용)
│  ├─ game_state.gd
│  ├─ rules.gd
│  ├─ effects.gd    # 이벤트/트리거 효과 처리
│  └─ market.gd
├─ ai/simple_ai.gd
├─ ui/              # 화면 (보드, 카드, 시장, 메뉴)
├─ tests/sim.gd     # AI끼리 N판 자동 대전 → 승률 통계
├─ assets/          # 아이콘, 폰트, 효과음
└─ docs/            # 기획서
```

### 13-3. 카드 데이터 형식 (예시)
```json
{
  "id": "F7",
  "name": "화염의 군주",
  "faction": "fire",
  "rarity": "legendary",
  "type": "unit",
  "cost": 7,
  "attack": 6,
  "health": 6,
  "keywords": ["charge"],
  "effects": [
    { "when": "on_play", "do": "damage", "target": "enemy_hero", "amount": 3 }
  ],
  "art": "icons/dragon-breath.svg"
}
```
→ 카드 추가와 밸런스 조정은 **JSON만 고치면 됨**.

### 13-4. AI (알파: 규칙 기반)
1. 이번 턴에 상대를 쓰러뜨릴 수 있는지 먼저 계산
2. 마나 효율이 높은 순서로 카드 사용
3. 쓰지 못하는 카드는 버려서 골드로
4. 살 수 있는 카드 중 점수가 가장 높은 것 구매 (희귀도, 진영 할인, 덱 상태 반영)
5. 공격: 유리한 교환이면 유닛 공격, 아니면 영웅 공격

정식판에서는 시뮬레이션 기반 AI(MCTS)와 난이도 단계를 검토.
