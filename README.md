# 아르카나 듀얼 (가제) — 알파 v0.1

공용 시장에서 카드를 사서 덱을 키우며, 유닛으로 싸워 상대 영웅을 쓰러뜨리는 **1:1 덱빌딩 결투** 카드게임.

- 엔진: Godot 4.7 (GDScript, Compatibility 렌더러)
- 플랫폼: Windows `.exe`, Android `.apk`
- 기획서: [`docs/design_v0.1.md`](docs/design_v0.1.md)

## 지금 들어간 것 (알파 v0.1)
- 1:1, 1:1:1, 2:2 (AI 대전과 온라인 모두)
- vs AI 난이도 8단계 (: 쉬움 · 보통 · 어려움 · 매우 어려움 · 헬 · 마스터 · 갓 · 얼티밋), 온라인 1:1 (방 코드)
  - 어려움부터 AI가 행동을 미리 해 보고 고름, 매우 어려움부터 AI 보너스(체력 30~50, 매 턴 골드·카드, 시작 마나)
- 튜토리얼 (19단계, 눌러야 할 곳을 화살표로 안내) + 게임 중 상황별 도움말 팁
- 영웅 12명 (기본 4명 + 영웅 뽑기로 얻는 8명, 새 영웅은 전용 카드 1장으로 시작)
- 영웅 뽑기: AI 대전에서 이기면 마석 획득 (쉬움 +30 ~ 얼티밋 +500), 마석 100으로 1회. 중복 없음
- 시장 카드 101장 + 스타터 4종 + 토큰 5종
  - 광역기 18장 추가: 모든 적 유닛 피해, 영웅 포함 피해, 무작위 적 여러 번 피해, 유언 폭발, 광역 필드 등
  - 시리즈: 드래곤 10장, 군주 8장(+기존 3장), 늑대·기사
  - 일반 카드의 상위 호환 레어 15장
  - 최대 마나 카드 (한도를 10 → 15까지), 이번 턴 마나 카드
  - 골드 수급: 약탈(공격하면 골드 +1), 턴마다 골드 주는 유닛·필드, 영웅 능력
- 조합 13종: 조건에 맞는 유닛이 모이면 결성 효과(체력 증가 등) + 조합 스킬 버튼, 결성 연출
- 유닛 / 주문 / 함정 / 공용 필드 / 영웅 카드
- 마나(자동 증가) + 골드(카드 버리기), 시장 구매·갱신·정리
- 시작 손패 교체, 붕괴(13턴부터), 승패 화면
- AI끼리 자동 대전 시뮬레이터 (밸런스 통계), 규칙 단위 테스트, 화면 자동 점검

## 실행하기
### 빌드된 파일로
GitHub의 **Releases**에서 최신 `알파 빌드`를 받으세요.
- Windows: `ArcanaDuel.exe` 실행. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요 (서명이 없어서 뜨는 경고입니다).
- Android: 폰에서 `ArcanaDuel.apk`를 받아 설치하세요. **출처를 알 수 없는 앱** 설치를 허용해야 합니다.

### 다인전 (1:1:1, 2:2)
- 메인 메뉴의 **대전 방식**에서 1:1 / 1:1:1 / 2:2 를 고릅니다. AI 대전과 온라인 둘 다 됩니다.
- 1:1:1: 셋이 각자 싸우고, 체력이 0이 되면 탈락. 마지막 한 명이 승리.
- 2:2: 나와 팀원(1·3번 자리) vs 상대 둘(2·4번 자리). 영웅·덱·체력은 각자, 상대 팀 둘을 모두 쓰러뜨리면 팀 승리. 팀원은 공격할 수 없고, 치료·강화 카드는 팀원에게도 쓸 수 있습니다.
- '적 영웅' 효과와 광역 피해는 모든 적에게 들어갑니다. 도발은 그 주인만 지켜 줍니다. 골드 빼앗기는 골드가 가장 많은 적에게서.
- 화면 위쪽에 다른 사람들의 요약 칩이 있고, 누르면 그 사람의 필드를 크게 봅니다. 다른 사람 차례에는 자동으로 그 사람을 보여 줍니다.

### 온라인 대전
- 메인 메뉴 → **[온라인 대전]** → 대전 방식을 고르고 한 사람이 **[방 만들기]** → 5글자 방 코드를 친구들에게 알려 줌 → 코드를 넣고 **[참가]**.
- 자리가 다 차면 바로 시작합니다. 다인전은 방장이 **[빈 자리는 AI로 채우고 지금 시작]** 을 누를 수도 있습니다.
- 빈 자리와 중간에 나간 사람의 자리는 방장 기기의 AI가 이어서 둡니다. 방장이 나가면 그 판은 끝납니다.
- 무료 공개 MQTT 중계 서버(EMQX / HiveMQ / Mosquitto 공개 서버)를 사용합니다. 계정이 필요 없지만, 공개 서버라 가끔 느리거나 끊길 수 있습니다.
- 모든 기기가 같은 시드로 같은 게임을 돌리고 '행동'만 주고받습니다(lockstep). 행동마다 전체 순번을 붙여 모두 같은 순서로 적용하고, 상태 지문을 비교해서 어긋나면 알려 줍니다.
- 메시지에 번호를 붙여 받을 때까지 다시 보내므로 잠깐 끊겨도 이어집니다. 90초 동안 연락이 없으면 상대가 나간 것으로 처리합니다.
- 한 턴 제한 시간은 90초입니다. 두 사람 모두 같은 빌드여야 합니다 (자동 업데이트가 맞춰 줍니다).

### 자동 업데이트
빌드 8부터 들어간 기능입니다.
- 게임을 켜면 GitHub의 최신 릴리스(`version.json`)를 확인합니다. 더 새 빌드가 있으면 패치 파일(`patch_windows.pck` / `patch_android.pck`, 약 3~4MB)을 받아 **바로 적용**합니다. 앱을 다시 설치할 필요가 없습니다.
- 인터넷이 없으면 확인을 건너뛰고 그대로 실행합니다.
- 엔진 버전이 바뀌거나 권한 같은 앱 자체 설정이 바뀌면 패치로는 안 됩니다. 이때는 메뉴에 **[새 버전 받기]** 버튼이 나옵니다. (`data/version.json`의 `min_app_build`를 올리면 이 상태가 됩니다.)
- Android는 같은 서명 키(`tools/debug.keystore`)와 매번 커지는 버전 코드(빌드 번호)를 쓰기 때문에, 새 APK를 설치하면 기존 앱 위에 업데이트로 설치됩니다.

### Godot 에디터로
1. [Godot 4.7](https://godotengine.org/download)을 설치합니다 (무료, 표준 버전).
2. Godot에서 이 폴더의 `project.godot`을 엽니다.
3. F5를 누르면 실행됩니다.

## 카드 수정하기
카드는 전부 [`data/cards.json`](data/cards.json)에 있습니다. 숫자나 문구를 바꾸면 바로 반영됩니다.
효과를 적는 방법은 [`docs/card_format.md`](docs/card_format.md)를 보세요.

## AI 난이도 비교
```bash
godot --headless --path . -s res://tests/ai_duel.gd -- 2 1 120   # 어려움 vs 보통 120판
```
커밋 메시지에 `[ai-tune]`을 넣으면 빌드 없이 이 대결만 GitHub에서 돌립니다 (`.github/workflows/ai_tune.yml`).

## 밸런스 시뮬레이션
```bash
godot --headless --path . -s res://tests/sim.gd -- 500
```
선공 승률, 영웅별 승률, 평균 게임 길이, 카드별 승률이 출력됩니다.

| `core/` | 규칙 엔진 (화면과 분리) |

| `assets/` | 글꼴 |

| `docs/` | 기획서 |
